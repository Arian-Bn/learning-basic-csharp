# C# Learning Basics

## Description
A structured console application designed to practice core C# programming concepts. The project features an interactive menu with robust user input validation to prevent crashes.

## Features
- **Project Info:** Displays details about the current learning phase.
- **Calculation:** Demonstrates basic arithmetic operations using methods.
- **Password Analyzer:** Validates user passwords based on length and emptiness.
- **Array Operations:** Iterates through integers to find the sum and maximum value safely.
- **List Demonstration:** Showcases dynamic data storage using 'List<T>'.

## How to Run
1. Ensure you have the .NET SDK installed.
2. Clone this repository to your local machine.
3. Open your terminal in the project directory.
4. Run the application using the following command:
 ```bash
 dotnet run
 ```
